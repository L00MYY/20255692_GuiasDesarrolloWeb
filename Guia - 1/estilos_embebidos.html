Estilos Embebidos en etiqueteas html

Usar estilos CSS embebidos en las etiquetas HTML es la peor manera y el menos utilizado en los metodos para agragar reglas de estilo. No es nada recomendable por la dificultad que implica realizar un cambion a posteriori.

Esta forma de incluir CSS directamente en los elementos HTML solamente se utiliza en determinadas situaciones en las que se debe incluir un estilo muy especifico para un solo elemento.

Para insertar un estilo CSS en un elemento se utiliza la propiedad style de HTML, que ningun momento se debe confundir con la etiqueta <style> ques se introduce en la cabecera del documento.
